  2.get():
      >>> b = Mobile.objects.get(name = "Lava A44")
      >>> print(b)
      Lava A44
      >>> print(b.price)
      4500.00
      >>> print(b.supplier)
      Bengaluru
      >>> print(b.ram)
      1

      2 Problems in get():
        1. Multiple objects returned
        2. Object does not exist



      try:
        a = Mobile.objects.get(name="Samsung F23")
        print(a)
      except Mobile.DoesNotExist:
        print("Mobile not found")
      except Mobile.MultipleObjectsReturned:
        print("Multiple data found")
      except Exception as e:
        print(e)

  3.filter():

    >>> a = Mobile.objects.filter(name = "Micromax")
    >>> print(a)
    <QuerySet []>
    >>> a = Mobile.objects.filter(name = "Samsung F23")

  4. update():

    1. using filter()
      Mobile.objects.filter(name = "Realme 5i").update(name = "Realme 5i Pro",price = 70000)

    2. using get()

      >>> print(a.price)

                                      Relationship in Django ORM
1. One to One- > One Row in a table is linked with only one row in another table
  ->One User can have only one profile
  -> One student can have only one ID
  ->One Person can have only one Passport

2. One to Many->One row in a table is linked with Multiple rows in another table
->One category - Multiple Products
3. Many to Many
->A student can enroll for multiple courses, in the same way a Course can have multiple students
